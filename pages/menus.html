Menüler

Tam ekran menü HTML yazılarak değil, veriyle kurulur: EUI.Menu(host, spec). Bölümleri (list, grid, settings, table, custom) ve öğeleri verirsin; katman, ekrana sığma, aç/kapa, ESC, ↑↓ / Q E ile gezinme, detay paneline göre 2/3 sütun ve alt ipuçları kitin işidir. Sahnede klavyeyle dene; her eylem sağdaki günlüğe düşer.

Son eylem:—

2 sütunlu menü

Hiçbir bölümde detay paneli yoksa menü kendiliğinden 2 sütun çizilir. Ayarlar view: 'settings': ↑↓ satır seçer, ←→ değeri değiştirir.

Kod

Yukarıdaki menünün iskeleti. Tüm alanlar ai/menu.md'de.

var menu = EUI.Menu('#screen', {
  kicker: 'Oyuncu menüsü', title: 'Etkileşim menüsü',
  stats: [{ label: 'Nakit', value: '$12.480', tone: 'success' }],
  sections: [
    { group: 'Oyuncu' },
    { id: 'inv',  label: 'Envanter', icon: 'backpack', view: 'list', items: [
        { id: 'carbine', title: 'Karabina tüfeği', sub: 'Otomatik tüfek', weapon: 'carbine', meta: '×1',
          stats: [{ label: 'Hasar', value: 64 }], actions: [{ id: 'use', label: 'Kuşan', key: 'E' }] } ] },
    { id: 'shop', label: 'Mağaza', icon: 'store', view: 'grid', cols: 3, detail: 'buy', items: [...] },
    { group: 'Sistem' },
    { id: 'set',  label: 'Ayarlar', icon: 'settings', view: 'settings', fields: [
        { id: 'scale', label: 'HUD ölçeği', type: 'slider', min: 70, max: 130, value: 100, unit: '%' } ] },
    { id: 'quit', label: 'Çıkış', icon: 'door', confirm: { title: 'Oyundan çıkılsın mı?', danger: true } }
  ],
  onAction: function (a) { /* a.action: open|close|section|select|activate|change|<eylem id> */ }
});
