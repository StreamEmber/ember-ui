Oyun ekranları

Açılış, giriş ve durum ekranları

Oyun açılırken ve bağlantı bozulduğunda görünen ekranlar. Her biri tek çağrı: EUI.title (dokununca devam), EUI.loading (ilerleme + ipuçları), EUI.state(tür) (ağ hatası, çevrimdışı, bakım, güncelleme, oturum, genel hata, bağlanıyor). Hesap ekranları da hazır: EUI.auth (giriş, kayıt, hesap bağlama, şifre sıfırlama, yayıncı girişi — e-posta, misafir, Google, Apple, QR), EUI.consent (koşullar ve yaş), EUI.language, EUI.nickname, EUI.pin (yetkili / ebeveyn kilidi). Ayarlar ise tam ekran EUI.Menu. Hepsi Promise döner: ne seçildiğini söyler. Aşağıdaki düğmeler iki ekranda birden çalışır.

Kod

Gerçek bir oyunun açılışı: başlık → yükleme → bağlantı hatasında yeniden dene → lobi.

await EUI.title('#screen', { name: 'Snowball', sub: 'Ember', version: '1.4.2' });
var ld = EUI.loading('#screen', { kicker: 'StreamEmber', title: 'Snowball', tips: ['Kartopu basılı tutunca güçlenir.'] });
ld.progress(.3, 'Sunucuya bağlanılıyor');
while (!(await connect())) {                                   // oyunun kendi bağlantı işlevi
  var r = await EUI.state('network-error', { code: 'NET-503' });   // 'retry'
}
ld.progress(1, 'Hazır'); ld.close();
EUI.Lobby('#screen', { … });

var s = EUI.state('reconnecting'); …  s.close();               // düğmesiz ekranı koddan kapat

// ilk açılış: koşullar → dil → giriş → ad
if (!(await EUI.consent({ age: 13 }))) return;
var lang = await EUI.language({ value: 'tr' });
var p = EUI.auth({ mode: 'login', name: 'Snowball', methods: ['email', 'guest', 'google'], resolveOn: false,
  onAction: function (a) { if (a.action === 'submit') api.login(a.values).then(p.done, function (e) { p.error(e.message); }); } });
var user = await p;                                             // null = geri
if (user.method === 'guest') user.name = await EUI.nickname({ suggest: ['KarTopu', 'BuzKıran'] });
if (await EUI.pin({ title: 'Yetkili menüsü', verify: isAdminPin })) adminMenu.open();
